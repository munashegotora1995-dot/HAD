### 🌟 About
Harare Small Business Hub is a Streamlit-powered classifieds platform for Harare entrepreneurs to post and discover local products & services.

### 🚀 Features
- 📢 Post ads with image
- 💬 Direct WhatsApp integration (263 format)
- 📍 Location filter - Harare suburbs
- 💾 SQLite local database
- 🎨 Luxury Gold & Navy design
